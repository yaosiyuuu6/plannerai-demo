# PlannerAI 项目管理 PRD

> 版本：v1.0
>
> 阶段：MVP
>
> 更新日期：2026-08-14
>
> 对应 Demo：`demo/agent-workbench.html`

## 1. 背景

用户的对话数量增长后，单一“历史记录”列表难以支持按业务主题管理。需要引入“项目”作为一层组织目录，让用户可以创建项目、将对话在项目之间移动，并对项目进行统一管理。

## 2. 产品目标

- 让用户可在 3 步内将现有对话归类到项目。
- 让用户可直接在某个项目下创建对话。
- 在不改变现有对话内容与运行方式的前提下，提升大量对话的可找回性。
- 通过强确认降低误删项目及项目内对话的风险。

### 2.1 建议指标

- 对话移动成功率 ≥ 99.5%。
- 项目创建成功率 ≥ 99.5%。
- 对话较多的用户中，项目功能 30 日渗透率作为核心观测指标。
- 因误操作产生的项目删除客诉率 < 0.1%。

## 3. 范围

### 3.1 MVP 范围

- 创建、搜索、重命名、删除项目。
- 左侧侧边栏按项目展示对话，项目和“对话”目录均可折叠。
- 将对话从“对话”移入项目、从项目移出，或在项目之间移动。
- 在项目下直接新建对话。
- 对话在所属目录内置顶。
- 项目删除时级联删除项目中的全部对话。

### 3.2 非 MVP 范围

- 项目文件、项目指令、知识库或共享上下文。
- 项目协作、成员、角色和权限。
- 多级项目或子文件夹。
- 对话同时归属多个项目。
- 项目回收站、删除撤销或恢复。
- 项目导入、导出、归档或分享。

## 4. 核心概念与规则

### 4.1 归属模型

- 一条对话任一时刻只能处于一个位置：“对话”或某一个项目。
- 顶层“新对话”创建的对话默认进入“对话”。
- 项目目录上的“新建对话”创建的对话直接进入该项目。
- 移动只改变归属，不改变对话 ID、内容、状态和共享链接。
- 移动当前打开的对话时，对话保持打开，仅左侧位置更新。

### 4.2 排序与折叠

- 项目目录在上，“对话”目录始终在所有项目之后。
- 项目默认按创建时间降序排列，新建项目排在第一位。
- 用户可在左侧目录或项目管理页拖动项目调整顺序；手动顺序跨页面同步并持久化，不会被对话活跃时间打乱。键盘聚焦项目后，可使用 `Alt + ↑/↓` 调整顺序。
- 新项目默认展开且为空，不自动创建首个对话。
- 项目和“对话”的折叠状态按用户持久化。

### 4.3 置顶

- 置顶仅在对话当前所属目录内生效。
- 多个置顶对话按最近置顶时间降序排序；其余对话按最近活跃时间降序。
- 对话移动到新位置后保留置顶状态，并在新目录内置顶。

### 4.4 项目命名

- 名称必填，保存前去除首尾空格，最长 30 个字符。
- 同一用户下不可重名；重名校验忽略大小写和首尾空格。
- 允许 emoji 和常见符号；禁止换行和控制字符。
- 重命名后，管理页、左侧目录和移动菜单同步更新。

### 4.5 删除

- 删除项目会级联删除项目内全部对话，不提供撤销或恢复。
- 确认弹窗显示项目名称和将被删除的对话数量。
- 用户必须输入当前完整项目名称；完全匹配后才启用“删除项目”按钮。
- 删除时同步清理项目与对话的置顶、折叠等关联状态。
- 若项目包含删除前打开的对话，删除成功后停留在项目管理页。
- 成功后提示“项目及其中的 N 个对话已删除”。

## 5. 信息架构

```text
左侧侧边栏
├─ 新对话
├─ 项目（进入全局项目管理页）
├─ 搜索问答
├─ 设置
├─ 项目 A
│  ├─ 文件夹图标 + 项目名称
│  ├─ 三点菜单：查看项目、重命名、删除
│  ├─ 方框铅笔图标：新建对话
│  └─ 对话列表
├─ 项目 B
│  └─ 对话列表
└─ 对话（未归类，固定最后）
   ├─ 文件夹图标 + 方框铅笔图标：新建未归类对话
   └─ 对话列表
```

## 6. 交互详情

### 6.1 全局项目管理页

- 点击左侧“项目”后，项目管理页覆盖工作区，但保留左侧侧边栏。
- 页面展示项目总数、搜索框、“新建项目”主按钮和项目卡片列表。
- 项目卡片展示名称、对话数、创建日期，并提供重命名和删除操作。
- 搜索对项目名称进行即时包含匹配；无匹配时显示空状态。
- 从项目目录三点菜单选择“查看项目”时，直接进入对应项目详情页。

### 6.2 侧边栏项目目录

- 侧边栏不展示独立的“历史记录”标题和对话总数，项目目录直接承接顶部功能入口。
- 每个项目目录及“对话”目录均在名称前展示统一的文件夹图标。
- 项目目录不展示独立的折叠按钮；点击文件夹图标、项目名称或项目行空白区域即可折叠/展开对话，不替换当前工作区。
- 鼠标悬浮或键盘聚焦项目目录时，最右侧显示三点菜单和方框铅笔的新建对话图标。
- 鼠标悬浮或键盘聚焦“对话”目录时，右侧显示方框铅笔图标；点击后在“对话”目录中新建对话。
- 三点菜单依次包含“查看项目”“重命名”“删除”；“查看项目”使用与左侧“项目”入口一致的文件夹图标，“删除”使用危险操作样式。
- 图标必须提供 Tooltip 和可读的 `aria-label`。
- 空项目展开后显示“暂无对话”。

### 6.3 对话菜单与移动

- 悬浮或键盘聚焦对话时显示 `···` 更多菜单。
- 一级菜单包含：置顶/取消置顶、移动到项目、改名、删除；不单独提供“移出项目”。
- “移动到项目”打开二级目标选择器；“对话”作为与各项目同级的首个目标，用于将项目内对话移回未归类目录。
- 当前所在的“对话”或项目不可选并显示“当前”。
- 项目选择器直接展示项目列表，不提供搜索框；移动完成后关闭菜单并显示轻提示。
- 所有菜单和弹窗必须支持 Tab、Enter 和 Escape。

### 6.4 新建与重命名

- 采用带明确标签的弹窗输入，不使用占位符代替标签。
- 新建成功后关闭弹窗，项目出现在管理页和侧边栏顶部，默认展开。
- 校验错误在输入框下方就近显示，并将焦点保留在输入框。

## 7. 状态与反馈

| 场景 | 界面反馈 |
|---|---|
| 项目创建成功 | Toast：“已创建「项目名」” |
| 项目重命名成功 | Toast：“项目名称已更新” |
| 对话移入项目 | Toast：“已移动到「项目名」” |
| 对话移出项目 | Toast：“已移出项目” |
| 项目列表为空 | 解释文案 + 新建项目主操作 |
| 搜索无结果 | “没有匹配的项目，试试其他关键词” |
| 请求失败 | 保留用户输入/当前位置，提示原因并提供重试 |
| 删除中 | 禁用弹窗操作，删除按钮显示加载状态 |

## 8. 数据模型建议

### Project

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 项目唯一 ID |
| `owner_id` | string | 所属用户 |
| `name` | string | 1–30 字符 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |
| `last_active_at` | datetime | 项目活跃度统计，不覆盖用户手动顺序 |
| `sort_index` | number | 用户手动顺序，数值越小越靠前 |

### Conversation 扩展

| 字段 | 类型 | 说明 |
|---|---|---|
| `project_id` | string / null | `null` 表示属于“对话” |
| `is_pinned` | boolean | 是否在当前目录置顶 |
| `pinned_at` | datetime / null | 多条置顶的排序依据 |

### UserProjectPreference

| 字段 | 类型 | 说明 |
|---|---|---|
| `project_id` | string / null | `null` 表示“对话”目录 |
| `is_collapsed` | boolean | 折叠状态 |

## 9. 接口建议

- `GET /projects?query=&cursor=`：获取项目列表及对话数量。
- `POST /projects`：创建项目。
- `PATCH /projects/{id}`：重命名项目。
- `PATCH /projects/reorder`：批量保存项目手动顺序。
- `DELETE /projects/{id}`：级联删除项目与其对话。
- `PATCH /conversations/{id}/project`：设置 `project_id` 或移出项目。
- `PATCH /conversations/{id}/pin`：更新置顶状态和时间。
- `PUT /project-preferences/{project_id}`：保存折叠状态。

服务端必须对项目归属、项目名重复、对话归属和删除权限进行最终校验；不可仅依赖前端。

## 10. 数据埋点

- `project_entry_clicked`：入口来源（侧边栏/项目目录三点菜单）。
- `project_create_submitted` / `project_create_result`。
- `project_renamed`。
- `project_delete_confirm_opened` / `project_delete_result`，记录对话数量，不记录项目名称。
- `conversation_move_opened` / `conversation_move_result`，记录起点和终点类型，不记录对话内容。
- `project_group_toggled`：展开/折叠。

## 11. 验收标准

1. “项目”入口位于“新对话”下方，点击后管理页覆盖工作区。
2. 项目可在左侧目录和管理页拖动排序，两处顺序保持一致并持久化；“对话”始终在最后。
3. 新建项目不自动创建对话，且默认展开。
4. 侧边栏不显示“历史记录”标题；项目和“对话”目录均展示文件夹图标。项目最右侧不显示独立折叠按钮，点击项目行即可折叠或展开。
5. 项目目录悬浮和键盘聚焦时，最右侧显示三点菜单与方框铅笔图标；“对话”目录显示方框铅笔图标。三点菜单可查看、重命名或删除项目，新建图标会在对应目录创建对话。
6. 对话可在“对话”、项目 A 和项目 B 之间任意移动，且不产生副本。
7. 移动当前打开的对话后，工作区不跳转。
8. 置顶对话仅在所属目录内排在首部，移动后保留置顶状态。
9. 项目名空值、超长和重名均无法提交，错误在输入框附近显示。
10. 删除确认中，未精确输入当前项目名时删除按钮不可用。
11. 删除项目后，项目与其中所有对话不再出现，并显示准确删除数量。
12. 图标按钮具有可读名称，键盘焦点清晰，弹窗可退出，动画遵循 `prefers-reduced-motion`。
13. 发布包构建与白名单校验通过，不携带 PRD 或其他内部文档。

## 12. 发布策略

- 第一阶段：内部用户灰度，验证移动、级联删除和排序正确性。
- 第二阶段：向高对话量用户开放，观察项目创建与对话移动转化。
- 第三阶段：全量开放，根据数据评估是否进入共享项目上下文或项目协作阶段。
